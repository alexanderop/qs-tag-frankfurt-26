# Rollen verschmelzen: Builder statt Silos

## Current synthesis

Anthropic-Leute beschreiben, dass Entwicklung, Produkt und Design verschmelzen und dass einzelne Personen trotzdem Spezialitäten behalten. Alex überträgt das auf QA: Builder mit Qualitäts-Spezialität. Die Testing-Szene hält dagegen, dass ein Tool keine Verantwortung tragen kann.

## Claims and evidence

- Der Titel Software Engineer wird an manchen Stellen durch „builder“ ersetzt. Boris Cherny, Lenny's Podcast 43:06. [raw](../raw/rollen-verschmelzen-notiz.md)
- Im Claude-Code-Team codet jede Rolle. Cherny 41:25. [raw](../raw/rollen-verschmelzen-notiz.md)
- Etwa 50 % Überlappung der Rollen, manche Leute haben Spezialitäten. Cherny 42:46. [raw](../raw/rollen-verschmelzen-notiz.md)
- „Our roles are blending together“. Cat Wu, Anthropic-Artikel. [raw](../raw/rollen-verschmelzen-notiz.md)
- Ein Mensch soll weiter auf den Code schauen. Cherny 17:13. [raw](../raw/rollen-verschmelzen-notiz.md)

## Tensions and open questions

- James Bach: Ein KI-Tool kann nicht verantwortlich sein, also keinen verantwortlichen Prozess tragen. Gleichzeitig erwartet er, dass Tester zu „generalist thinkers“ werden. [raw](../raw/rollen-verschmelzen-notiz.md)
- Weder Cherny noch Wu nennen QA ausdrücklich. Die Übertragung auf QA ist Alex' eigene These.
- Vor QS-Publikum kann „alle können alles“ wie eine Drohung klingen. Darum Spezialität und Mut-mach-Wendung betonen.
